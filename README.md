# monkdoesstuff.fun

Monk's games & projects site. Static — no build step; deploys to Cloudflare
Pages as-is.

- `index.html` — Games (default page): Hookline link + coming-soon cards
- `projects.html` — Projects (placeholder for now)
- `css/site.css` / `assets/` — styling (hookline.fun house style) + logos
- `games/` — static copies of the games for future early-access hosting
  (see `games/README.md` — secrets and local servers are stripped; live
  TikTok play always runs from the local dev folders, not from here)
